ЗАПУСК КАРЬЕРНОГО TELEGRAM-БОТА

1. Открой .env и замени ВСТАВЬ_СЮДА_ТОКЕН на токен от @BotFather.
2. В CMD перейди в эту папку.
3. Выполни: python -m pip install -r requirements.txt
4. Выполни: python bot.py
5. В Telegram отправь боту /start.

Структура:
career_bot/
  bot.py
  .env
  .gitignore
  requirements.txt
  README.txt
  data/
    professions.json
